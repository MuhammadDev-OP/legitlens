# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please **do not** open a public issue for security flaws that could harm users (e.g. spoofed verdicts, supply-chain issues, XSS in the popup).

Email or privately message the maintainer via GitHub: [@MuhammadDev-OP](https://github.com/MuhammadDev-OP).

Include:

- Affected package (`packages/rules`, `apps/extension`, `apps/web`)
- Steps to reproduce
- Impact assessment

You should receive an acknowledgement within 7 days.

## Scope notes

- False positives / false negatives in scoring are product bugs — use the **false positive** or **report a scam site** issue templates, not this process.
- RDAP and third-party list freshness are best-effort; treat verdicts as a second opinion, not a guarantee.
